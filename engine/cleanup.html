Clean-up review: other versions of your projects

Each project in your projects folder is the kept version. Below are the other versions found elsewhere, compared with it file by file and by git history. Tick the ones you no longer need and press “Move to holding folder”. Nothing is deleted: a ticked version is renamed into and can be put back with one click. Projects on the Desktop and protected projects are never listed.

Safe nothing in it that the kept version lacks (ticked for you). Probably at most 5 files differ. Different has files or git commits the kept version does not have: look before ticking.
