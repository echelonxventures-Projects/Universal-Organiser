Working projects and iCloud

iCloud syncing code projects (with .git, node_modules, .venv) makes them slow and can leave files “in iCloud only”, which breaks builds. Here you can stop iCloud syncing a project without moving or renaming it: the folder keeps its exact path, so editors, terminals, Docker and scripts are unaffected. First every iCloud-only file is downloaded and checked, and it must not be in use. Afterwards iCloud no longer backs it up, so git (pushed) and Time Machine are its backup. Undo = “Resume sync”. Protected projects are never touched.

Working status (Active, Paused, Completed, Experiment) is kept here and shown as a Finder tag on the project folder. Changing it never renames or moves the project.
